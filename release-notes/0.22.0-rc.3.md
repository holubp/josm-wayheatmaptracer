# WayHeatmapTracer 0.22.0-rc.3

Reissued on 2026-09-29 with node-only **Select Longest Heatmap Segment**
and corrected segment boundaries.
Select a node alone when exactly one live way contains it; the helper chooses
the eligible junction-bounded section containing that node. For a shared node,
select the intended way too. Incomplete geometry and repeated-node ambiguity
remain rejected. This update changes selection only, not tracing or Apply.
T junctions and more complex junctions are now excluded from the returned
range, including its endpoints. Exactly two complete ways meeting once at
their respective endpoints may remain as a simple continuation. Ranges are
ranked after trimming; fewer than two remaining nodes produces a visible
refusal. An explicit unsafe-junction hint can choose an adjacent trimmed range.
Trimming uses existing nodes and does not introduce a physical buffer.

This candidate repairs ordinary modern Precise Shape Apply for authorized,
untagged, unshared interior nodes. The preview still requires complete candidate
assignments, fresh source and network validation, and explicit confirmation when
review is required. Protected junction vicinities remain untouched. Apply, Undo
and Redo continue through the existing locked command transaction.

New Format-15 captures preserve the exact certified numerical frame and include
bounded output companions from the already computed production result. Strict
replay can compare inference, geometry, assignments, provenance and quality
components separately while retaining the original final fingerprint as its
acceptance check. Measured image-center cost and roughness remain distinct from
unavailable quality. Optional companions that exceed the existing budget are
unavailable; malformed inputs and privacy violations are rejected.

Use **More tools → Align Way to Heatmap**, inspect the preview, then choose
**Export Last Alignment Diagnostics** (Ctrl+Alt+Shift+D) before another alignment.
Export does not require Apply. Please first provide one fresh diagnostic capture
to verify the repaired replay path before recapturing the fourteen reference
cases. Keep the original RC.2 archives unchanged: their missing output details
cannot be recovered retrospectively.

The six experimental Engine menu launchers remain removed. Validation warnings,
manual-junction safeguards and source acquisition limits are unchanged. This is
a diagnostic release candidate, not final 0.22.0: the fourteen-case strict replay,
calibration, ablation and remaining release gates must still pass.

Independent Sol/high reviews approved the original frame, Apply and output-companion
repairs. The original clean Java/build/Javadoc/tools gate passed 1,272 tests in 139 suites,
with zero failures, errors or skips, in 22m28s. Javadoc reported 100 warnings.
Python checks passed 118 tests and five subtests, byte compilation, and 1,945
sampling-scale cases. Both staged and working-tree whitespace checks passed.
The final selection-only reissue passed 42 focused action, selector and selection-resolver
tests with zero failures, errors or skips, plus JAR construction and whitespace
checks. The original full suite was not rerun for this bounded update.
