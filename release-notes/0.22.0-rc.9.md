# WayHeatmapTracer 0.22.0-rc.9

This is a test release candidate for JOSM 19555, not stable 0.22.0.

## Changes

Engine B now requires a localized, two-sided center along a proposed trace
continuation. Diffuse brightness alone cannot prove that a narrow trace
continues between observations. Confidence and amplitude deterioration reduce
this continuation evidence continuously. Endpoint references use the same
sampling direction, preserving genuinely concentrated faint bends.

The search states, exact optimization, weights, and topology/Apply guards remain
unchanged. Sampling and localization work have separate bounded budgets and
cancellation checks. Production replay receipts identify the new reliability
policy; older diagnostic bundles remain readable but cannot certify this policy.

## Testing and limits

Install in a JOSM test profile and compare the exact preview with RC8, especially
on faint concentrated bends and weak dispersed traces. This is a bounded evidence
correction, not a claim that weak-trace zigzagging is fully resolved.

Production comparisons on five distinct Ricany inputs and two Maganik paths
show less accumulated turning on affected paths, but some also lose direct
image support. On the 1.3 km mixed Maganik path, the longest unsupported run
grows from approximately 55 m to 72 m. Review-required and truncated-alternative
warnings remain visible; no image-support or crossing guard is waived.

RC8's fixed-junction, protected-context and inherited-ridge corrections remain.
Genuinely incomplete topology and administrative-boundary contact refusals
remain blocked. Stable 0.22.0 still needs its alternative-completeness,
visible-freshness, reference-corpus quality and final release gates. The 256 MiB
whole-attempt memory gate and METHODS.md remain deferred to 0.22.1.
