# WayHeatmapTracer 0.22.0-rc.15

Testing prerelease for JOSM 19555, focused on the Legacy tracer's Drasov fixes.

- Reduces unsupported Legacy zigzags caused by sampling-frame changes and
  competing peaks, using source-resolution-aware continuity and bounded local
  corrections. It keeps the existing fast tracker rather than adding a new solver.
- Preserves fixed anchors and existing junction protections. Safety checks inspect
  the final preview, including geometry reconstructed around fixed endpoints.
- Reuses Legacy anchor analysis across seeds and avoids repeated support scoring.
  Retained scratch memory is accounted for explicitly; resource limits are unchanged.
- Records the effective sampling and numerical policies in versioned diagnostics
  and replay evidence. Historical policy identities remain available.

The approved Drasov geometry is preserved exactly. Ten other captured ways across
five palettes retain identical measured mean error, maximum error and acceptance
envelope results. Public synthetic tests cover supported bends, competing strands,
fixed anchors and cancellation. Private captures are not uploaded.

Select the Legacy tracker to test these changes. Engine choices, palette settings,
search widths and opt-in junction movement settings are unchanged.

This is not stable 0.22.0 qualification. Remaining Corridor A work, broader filter
experiments, Probabilistic B's wide-search limits and outstanding stable-release
gates are separate. Benchmark results describe the tested cohorts, not a latency
guarantee for every machine or way.
