# WayHeatmapTracer 0.22.0-rc.1

This is a test candidate for recapturing the fourteen reference alignments as
Format-15 diagnostics. It is not the final 0.22.0 release.

Use the ordinary **More tools → Align Way to Heatmap** action. It supports the
modern A, Probabilistic B, Hybrid, and Directional Image routes through one
modeless preview. With managed tiles configured, an applicable composed interval
plan can Apply as one JOSM Undo command. Tagged, relation-protected, and other
unproved junction vicinities stay fixed while independently safe intervals may
move. Inspect the exact preview and adjust difficult junctions manually first.

For each reference case, rerun the ordinary action with this JAR and use
**More tools → Export Last Alignment Diagnostics** immediately after the
attempt. Keep the resulting Format-15 archive with its existing human annotation
and case identity. Export preview and terminal attempts, including blocked and
cancelled attempts; Apply or Cancel does not itself mean a candidate was good or
bad. Do not include credentials when sharing archives.

Generic visible-layer interval previews are currently read-only because their
source has no authoritative revision for a safe interval Apply. Narrow
single-range visible A/B Apply retains its existing guards. The six explicit
experimental launchers and analysis controls remain in this RC for comparison;
the approved final-release plan removes them after recapture and parity checks.
Slight attraction toward a diverging heatmap fork remains a candidate for
0.22.x improvement. The fourteen-case strict replay, calibration, ablations,
and final release audit follow the recapture.

The clean RC build passed 1,235 Java tests in 135 suites with no failures,
errors, or skips, plus JAR, Javadoc, and tools compilation. Javadoc reported
100 missing-`@param` warnings. Script verification passed 118 Python tests
and five subtests, 1,945 sampling-scale cases, and Python byte compilation.
