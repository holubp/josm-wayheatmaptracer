# WayHeatmapTracer 0.22.0-rc.12

Unpublished test release candidate for JOSM 19555. Final public validation,
graphical host checks, independent whole-change review and artifact checks remain
required before publication. This is not stable 0.22.0.

Independent map features crossing, touching or overlapping a proposed path can
now be reviewed without treating geometric contact as a shared-node connection.
Apply requires confirmation of the exact preview. Waterway contacts ask the
mapper to check bridge, culvert, tunnel or ford handling; no tags or contextual
geometry are changed automatically. Self-intersections, unsafe geometry, stale
sources and missing edit authority retain their safety controls.

The modeless preview offers an explicit session-local choice to disconnect
eligible shared nodes from the selected way. Preservation remains the default.
Changing or clearing choices recomputes the preview and resets confirmation.
Disconnection and sliding form one undoable command in Precise Shape and Move
Nodes. Original shared nodes, other ways and relations remain unchanged.
Tagged or relation-sensitive cases require manual handling.

Diagnostics retain contact findings, original occurrence identities, replacement
identities and exact-plan confirmation evidence. Versioned replay validates new
authority through the production planner; old bundles retain their native
identities and gain no inferred disconnection permission. Unsupported non-FIXED
contact-receipt replay is explicitly unavailable. Failure diagnostics remain
accessible from the current attempt's modeless UI.

This release changes contact review and explicit edit authority. The tracing
algorithm is unchanged. Stable-release corpus, calibration, visible-source and
observation-model work remains separate; an RC is not a claim that those goals
are complete.
