# WayHeatmapTracer 0.22.0-rc.4

This local test candidate advances the ordinary managed Engine B preview.
Probabilistic inference now reports complete-path alternative and cumulative
work limits truthfully, uses the reviewed deterministic numerical policy, and
accounts for its own retained memory without changing admitted states or
under-limit route ordering. Final-preview repeated short waves are assessed
using physical local windows and direct image evidence, rather than a
whole-route turn count. Structural, topology, source-freshness and manual
junction safeguards remain in force.

Use **More tools → Align Way to Heatmap** with Engine B, Precise Shape and a
managed heatmap source. Inspect the exact candidate, confirm any review-required
preview, and Apply only when the heatmap and other mapping evidence justify it.
Export diagnostics with **Export Last Alignment Diagnostics** before starting
another alignment; export does not require Apply. Please capture the strong and
weak reference ways with this RC. The older six Format-15 captures predate the
new numerical policy and correctly fail strict replay as
`numerical-policy-unattested`; they remain useful historical geometry evidence
but cannot validate this build's exact output.

256 MiB whole-attempt memory gate and scientific methods document to 0.22.1.
Engine B practical quality, fresh production replay, safe Apply and final
release validation still need current evidence. Complex/tagged/relation
junctions remain manual; a review confirmation never overrides a hard block.
