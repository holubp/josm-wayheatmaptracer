# WayHeatmapTracer 0.22.0-rc.8

This is a test release candidate for JOSM 19555, not stable 0.22.0.

## Changes

- A complete unchanged `natural=ridge` line can retain a proved original proper
  crossing as review-required. All existing contact, displacement and freshness
  proofs still apply. New crossings, touches, overlaps and uncertain context
  remain blocked; context ways and nodes remain unchanged.
- Engine B captures bounded read-only geometry around selected endpoint
  junctions so fixed junction approaches can coexist with safe interior sliding.
  Complete watched receiver-relation evidence is retained in the fixed-island
  proof. Unknown geometry and stale evidence still refuse Apply. Both Precise
  Shape and Move Existing Nodes retain exact protected approaches.
- Engine B integrates measured orientation evidence at both ends of each
  segment, correcting direction-dependent weak-strand departures. Missing
  evidence contributes zero; no path averaging or post-processing smoothing is
  added. The objective is versioned in production replay receipts.

## Testing and limits

Install `wayheatmaptracer.jar` in a JOSM test profile, restart, and verify the
Plugins dialog shows `0.22.0-rc.8`. Review the exact preview before confirming
and applying a review-required candidate.

Both recorded inherited-ridge failures pass the complete contact proof with
this change. The recorded path-junction case now proves fixed endpoint
approaches and a safe interior partition, but its separate approximately
18 m gap without direct image support still prevents Apply. No support or
crossing guard is waived.

The orientation correction passes analytic departure/reversal and supported
bend controls, but leaves the recorded weak Maganik paths unchanged. Improved
fitting of separated weak traces is not established by this RC.

Strict alternative completeness, visible-render freshness parity and the
reference-corpus quality gate remain stable-release blockers. Truncated
alternative searches are not certified by strict replay. The whole-attempt
256 MiB memory gate and `METHODS.md` remain deferred to 0.22.1.

Independent review and final CI/private validation are pending; this file is
a release draft until those checks and downloaded JAR verification finish.
