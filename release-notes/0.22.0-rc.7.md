# WayHeatmapTracer 0.22.0-rc.7

This is a test release candidate for JOSM 19555, not the final 0.22.0 release.
It includes the recent managed Engine B ordinary-action work and is intended
for careful preview-and-review testing.

## Changes in this candidate

- Engine B's ordinary alignment action supports both `Move Existing Nodes` and
  `Precise Shape`. The Move path preserves existing node identities and order;
  Precise Shape can add shape nodes. If Move cannot represent an undersampled
  curve safely, the preview offers one explicit Precise Shape rerun without
  changing the saved mode. An already-aligned result is a successful no-op
  without an Undo entry.
- Context ways are projected as certified read-only evidence for topology
  checks. Selected interval boundaries and protected junctions remain fixed.
- Preference normalization uses one effective invocation for capture, preview,
  and Apply while preserving the user's saved settings for later runs.
- Managed Engine B supports opt-in alternative mappings for the selected source
  and a complete five-color aggregate over `hot`, `blue`, `bluered`, `purple`,
  and `gray` tiles from the same sampling frame. A missing palette does not
  become partial aggregate evidence.
- Bounded K-best candidate selection has a deterministic indexed search while
  retaining its exact search contract. The private performance target has not
  yet been established.
- The preview adds a compact summary of candidate quality and findings.
- `Select Longest Junctionless Segment` is selection-only and uses
  `Ctrl+Shift+J`; alignment remains a separate action on `Ctrl+Shift+Y`.

## Install and test

Install `wayheatmaptracer.jar` into a JOSM 19555 test profile and restart JOSM.
Confirm the Plugins dialog reports `0.22.0-rc.7`. Configure the managed
Strava source before testing Engine B. Select a way or segment, optionally use
`Ctrl+Shift+J` to choose a junctionless range, then run alignment and inspect
the modeless preview. Apply only after confirming the proposed geometry.

## Verification and remaining limits

Public CI run 37892311974 passed the public Java validation and real GUI smoke
on source matching commit `a5adf9e`. That run predates only this RC metadata
change, so a fresh RC7 build and JAR manifest/checksum verification remain
pending. In the separate synthetic route case, the default choice was `route 0`;
the GUI smoke does not establish that automatic ranking always chooses
the best route. Review the candidate list and preview geometry before
applying.

Strict alternative-completeness proof, visible-render freshness parity, and
the reference-corpus replay gate remain open. The private performance
comparison is still pending; this candidate makes no 2x speedup claim, and
shared CI timings are not performance evidence. The shared 256 MiB whole-attempt
memory gate and scientific `METHODS.md` are deferred to v0.22.1. These open
items prevent stable 0.22.0 release readiness; they do not turn this test RC
into stable software.
