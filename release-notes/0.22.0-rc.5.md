# WayHeatmapTracer 0.22.0-rc.5

This test candidate corrects Engine B's final-preview `UNSUPPORTED_ISOLATED_EXCURSION` reports. The evaluator now checks local image evidence around an exact final-preview bend. When the local signal cannot distinguish the bend from incomplete or competing evidence, it reports a review ambiguity instead of claiming the excursion is unsupported. Structural, topology, source-freshness, fixed-anchor, and manual-junction guards remain in force.

Across eight private RC.4 Format-15 captures replayed with the correction, unsupported-excursion findings fell from 6,709 to 4; 677 local windows became explicit image-ambiguity reviews. The inferred paths and other final-output components matched the RC.4 captures. This is evidence about warning attribution, not a user quality rating or proof of Apply safety for those attempts.

Use **More tools → Align Way to Heatmap** with managed Engine B and Precise Shape. A partial inner segment may be selected to leave difficult junctions unchanged. Inspect the exact preview, confirm review-required candidates only when justified by the visible heatmap and other map evidence, and use **Export Last Alignment Diagnostics** before starting another alignment. Export does not require Apply.

This is a test candidate, not final 0.22.0. All eight RC.4 captures reached the 32-raw-path alternative-search cap before eight distinct routes were proven, so strict production replay correctly reports incomplete alternative search. This concerns competing-route evidence, not whether the selected segment was traced end to end. A bounded distinct-route completion proof and the remaining release gates are still required. The maintainer deferred the shared 256 MiB whole-attempt memory gate and scientific methods document to v0.22.1.
