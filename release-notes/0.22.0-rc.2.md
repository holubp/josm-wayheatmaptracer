# WayHeatmapTracer 0.22.0-rc.2

This recapture candidate fixes Format-15 export for modern previews whose image
quality is unavailable. Such previews previously failed bundle creation with
`IllegalArgumentException`. Export now preserves the exact unavailable quality,
validation findings, and disposition; existing finite replay fingerprints remain
compatible. Failed export diagnostics use bounded safe cause codes.

The six separate Engine Visible/Managed analysis launchers are removed from the
menu. Choose A, Probabilistic B, Hybrid, or Directional Image in settings and use
the ordinary **More tools → Align Way to Heatmap** action.

To capture a result, run the ordinary alignment action, inspect the preview, then
choose **More tools → Export Last Alignment Diagnostics** before starting another
alignment. The shortcut is **Ctrl+Alt+Shift+D**. Export works without Apply,
including read-only, review-required, blocked, and failed attempts. After a
manual-junction message, dismiss it and export that attempt immediately. The ZIP
contains `replay-manifest.json` with `formatVersion: 15`. Keep each archive with
its case identity and human assessment; Apply or Cancel is not a quality label.

The existing Apply guards remain in effect. Generic visible-layer interval
previews remain read-only; managed interval plans require complete source,
geometry, and occurrence authority. This candidate does not remove validation
warnings or make unsafe candidates applicable. Other analysis controls remain
until the later approved cleanup stage. Final 0.22.0 still requires the fourteen
fresh Format-15 cases, strict replay, calibration, ablations, and release audits.

Independent Sol/high review found no blocking issue. The full clean Java gate
passed 1,238 tests in 135 suites with no failures, errors, or skips, plus JAR,
Javadoc, and tools compilation. Javadoc reported 100 missing-`@param` warnings.
Script checks passed 118 Python tests and five subtests, 1,945 sampling-scale
cases, and Python byte compilation. The focused nine-suite gate passed 98 tests.
