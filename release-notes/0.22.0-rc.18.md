# WayHeatmapTracer 0.22.0-rc.18

This release candidate repairs the stepwise refinement workflow in Move Existing Nodes and Precise Shape. The preview still offers every available color detector, including the combined all-color result when enabled. Refine A, Refine B, and Smoothen work from the selected preview. Use Undo to return to the previous preview and try another detector.

When a junction or a local refinement failure prevents an interval from being refined, the preview can carry finished intervals alongside the selected parent geometry. Inspect and confirm results that require review before applying an edit.

Install `wayheatmaptracer.jar` and restart JOSM. The minimum supported revision is 19555.
