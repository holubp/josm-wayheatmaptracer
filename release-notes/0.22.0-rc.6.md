# WayHeatmapTracer 0.22.0-rc.6

This test candidate fixes the managed preview failure `A nondegenerate polyline and positive metric radius are required` when a selected way has a complete receiving way attached at one node. That receiving junction remains protected; its one-node local capture no longer calls the polyline corridor constructor.

It also includes the committed Format-15 replay correction for missing corridor input in recorded modern attempts.

Managed modern preview can now use Direct luminance, Direct max channel, or Direct alpha as the scalar source for the selected palette. The captured mode is frozen through evidence production and checked against evidence lineage before Apply. Color detector options stored from earlier versions are inactive for these direct modes.

Blue, Gray, Purple, Hot, and Blue-red remain selectable as individual managed color-mapped sources. For color mapping, **Run alternative detector mappings on current source** and **Aggregate all managed color schemes into one intensity map** are still unsupported by the modern preview. Turn both off in Heatmap settings when testing a single selected palette. The error now names these settings. The aggregate visualization layer is diagnostic and does not supply tracing evidence. Full five-palette tracing remains an open v0.22.0 release item.

Use **More tools → Align Way to Heatmap** with managed Engine B and Precise Shape. Inspect the exact preview before Apply. Export Format-15 diagnostics before another alignment; export does not require Apply.

This is a test candidate, not final 0.22.0. Strict alternative completeness and the remaining release gates are still open. The maintainer deferred the shared 256 MiB whole-attempt memory gate and scientific methods document to v0.22.1.
