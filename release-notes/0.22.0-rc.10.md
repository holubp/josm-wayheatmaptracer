# WayHeatmapTracer 0.22.0-rc.10

This is a test release candidate for JOSM 19555, not stable 0.22.0.

## Changes

Engine B and Hybrid now sample the complete configured search half-width,
including the residual interval when the width is not a multiple of the
sampling step. Every interval must remain inside the authorized decision and
evidence regions. Unavailable geometry and resource failures still fail safely.
Symmetric windows retain a center sample rather than shifting a centered ridge
by half a sampling cell.

The exact K-best solver avoids computing prefix scores that provably cannot
enter its retained set. For identical sampled profiles it preserves the state
space, objective, rounded score ordering, ties and returned geometry. Its unchanged 128M ordinary B work limit
now charges scores actually computed. Diagnostics distinguish those scores
from logical extensions; Format-15 receipts bind every executed B stage to
the recorded computation, including guided Hybrid and multi-interval runs.

Visible Hybrid also uses the existing safe-interval workflow around manual
endpoint junctions. Related receivers and frozen approaches remain exact;
junction adjustment off is now described correctly in the preview. Managed
Hybrid remains unsupported; managed B remains available in both geometry modes.

An unchanged ordinary endpoint may tolerate a bounded prefix of complete
two-sided localization ambiguity when direct support resumes. The extra bound
is one explicitly known constant native pixel. Fixed-junction seams, missing
imagery, no-signal areas and unsupported terminal turns gain no allowance.

## Testing and limits

Seven private Ricany/Maganik captures completed through production B at default
limits. The 1.3 km mixed Maganik case used 89.9M computed scores, where the
previous full-window implementation exceeded 128M. All 18 raw/final geometry
files for the six previously admitted captures were byte-identical to their
full-window eager counterparts. These local comparisons prove execution
parity; they do not certify image quality, alternative completeness or Apply.

Weak dispersed-trace zigzags and truncated-alternative warnings remain open.
This is an execution and sampling correction, not a claim that weak-signal
fitting is fully resolved. Review confirmation, topology, source freshness and
immutable Apply/Undo/Redo guards remain required. RC9 remains unchanged.

Final public CI, graphical JOSM host, integrated private fixtures and artifact
verification must pass before publication. Stable 0.22.0 corpus, calibration,
alternative-completeness and final release gates remain separate. The 256 MiB
whole-attempt gate and METHODS.md remain deferred to 0.22.1.
