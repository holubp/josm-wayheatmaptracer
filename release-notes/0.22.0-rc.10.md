# WayHeatmapTracer 0.22.0-rc.10

**Unpublished draft.** This is a test release candidate for JOSM 19555,
not stable 0.22.0. The test and benchmark decisions are approved. Publication
still requires the fresh paired benchmark, public CI and artifact checks.

## Changes

Engine B uses the complete configured search width and keeps a sample at the
center of symmetric windows. It estimates image noise from normalized changes
in slope, reducing the chance that a smooth ridge is mistaken for noise.

Weak-signal fitting uses measured support along a strand. Recovery of a weak
peak requires its own image evidence, a unique compatible branch, and evidence
on both sides. Clipped evidence cannot invent a ridge center or count as direct
support. Supported bends remain eligible; ambiguous parallel strands are not
averaged into a new path. These corrections run before the existing optimizer,
with no smoothing of its completed geometry.

The exact K-best solver avoids calculations that cannot enter its retained
alternatives. For identical input profiles, it preserves the objective, ties,
state space and returned paths. The ordinary 128M work limit is unchanged and
counts scores actually computed. Format-15 diagnostics bind the computation
policy and each executed stage to the recorded inputs.

Snapshot hashing preserves the original diagnostic identities while removing
repeated hexadecimal-formatting work. Its whole-action speed effect has not
yet been measured.

Visible Hybrid uses the existing safe intervals around manual endpoint
junctions. Frozen approaches and receivers remain exact. Managed Hybrid is
unsupported; managed Engine B supports Precise Shape and Move Nodes.
Review confirmation, source freshness, topology checks, and immutable
Apply/Undo/Redo remain required.

## Verification still in progress

All seven supplied Ricany/Maganik captures complete under the default limits.
Compared with the preceding fitting implementation, current replays reduce
turning and improve supported length in several weak-trace cases. One Ricany
case has a longer unsupported gap, so these results are not a blanket quality
guarantee. The retained production tests preserve the isolated-impulse bound,
three overlapping sparse strands, a faint supported 12-metre bend, and a gap
without direct image support.

The earlier public suite completed 1,964 tests with one disputed synthetic
connector expectation. Following visual review, the crossing fixture is now
a safety test and a separate non-crossing fixture checks both supported bends.
The composer/Apply adapter suites passed 135 tests; the final strengthened
connector checks passed three tests. Independent review found no blockers.
The private fixture suite passed 20 tests. The newer hash and receipt regression
batch passed 31 tests. The corrected local real GUI check passed. The approved
benchmark contract passed 105 Java tests and independent review, and the full
Python scripts suite passed 185 tests plus five subtests. The fresh paired
whole-action benchmark and public CI remain pending. Earlier passing runs do
not certify the final release tree.

Alternative-search warnings may remain. Stable 0.22.0 still has separate
corpus, calibration, alternative-completeness, visible-source and final-release
gates. The whole-attempt 256 MiB limit and METHODS.md are deferred to 0.22.1.
RC9 remains unchanged. Development commits and CI artifacts are not public
release candidates.
