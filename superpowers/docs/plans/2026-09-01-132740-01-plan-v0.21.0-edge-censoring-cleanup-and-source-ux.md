# v0.21.0 Edge Censoring, Local Cleanup, And Source UX

**Goal:** Prevent search-boundary observations and short unsupported motion from producing inexplicable geometry, make optional cleanup effective and visible away from local defects, and make source/display status truthful.

**Why planning is required:** The change crosses scalar-profile interpretation, longitudinal association, one exact second-order optimizer, optional geometry cleanup, modeless preview retries, managed and visible sampling, tile health UX, additive private diagnostics, and topology-safe application. A local-looking correction can otherwise flatten a real switchback, jump to a parallel trace, fabricate cleanup evidence around a shared node, change legacy behavior, or misstate current source availability.

**Target:** `0.21.0`. The edge-observation semantics and explicit retry workflow are material behavior improvements beyond a patch-only release.

**Baseline:** public `v0.20.3` / `391014396f759c490672ffb2038c4a2b72a612ab`. The pre-existing untracked `exceptions.txt`, `human-guesstimate.osm`, and `human-guesstimate2.osm` are outside the mutation boundary. `problems-7.zip`, its nested debug bundles, `manual-improve.osm`, and generated `build/debug-problems-7/` analysis remain private, ignored, and read-only.

**Acceptance:** The two `problems-7` search-edge excursions no longer become direct positional evidence or applicable false bends; complete broad high-intensity corridors center materially better without added high-frequency motion; real low/medium-intensity turns and switchbacks retain their shape; an explicit retry can rerun the unchanged selection at a user-approved larger physical half-width without changing saved settings; a nonadjacent protected anchor freezes only its smallest safely bounded neighborhood while other intervals can produce one partial cleaned sibling; cleanup status is unmistakable in preview; source probes distinguish fresh network, cache, spatial no-tile, and authentication outcomes; legacy tracking and cleanup-disabled non-censored controls remain unchanged; diagnostics stay credential-free and old bundles remain readable.

## Scope And Design Decisions

1. Implement edge option **A**, per-band censoring with conservative longitudinal bridging, as mandatory corridor-aware behavior.
2. Implement edge option **B** as an explicit modeless-preview action. It is a one-shot physical-width override, defaults to twice the slide-time width, is editable and bounded by the selected sampler's representable limit, and never changes saved settings.
3. Re-sample the complete selected segment for a retry so every detector uses one coherent frame. Do not stitch locally widened profiles into the old run, merge completed geometries, or add hidden refinement.
4. Preserve elementary mode identity. The deferred semantic classifier for uncertain broad trails, double-tracks, lanes, and separate ways is recorded in `PLANS.md` but is not part of this release.
5. A boundary-censored observation may prove signal existence but not a point center, direct coverage, turn support, endpoint movement, or cleanup authorization.
6. Cleanup defects are local frozen islands. No remote profile borrowing, fabricated sampling row, or whole-way simplification across an island is permitted.
7. JOSM's `No tiles at this zoom level` behavior is not changed until runtime diagnostics identify the exact layer and current/best/display relationship. The plan may add safe observability before that gate.
8. `TrackerMode.LEGACY_V02` is outside the algorithm mutation boundary. Explicitly stored legacy settings and output fixtures must remain unchanged.

## Stop Conditions

1. Stop if clipped evidence must be assigned a point center to keep current candidates applicable.
2. Stop if a bridge would flatten an unresolved apex/switchback rather than prove ordinary continuation.
3. Stop if wider retry would mutate persistent settings, reuse old profiles, or acquire sources without an explicit user action.
4. Stop if complete broad-core centering changes elementary track identity, merges persistent parallels, or adds a post-optimizer smoothing pass.
5. Stop if local cleanup requires remote profile borrowing, fabricated evidence, moving a protected anchor, or simplifying across a frozen island.
6. Stop if a preview retry or cleaned sibling cannot rebuild fresh candidate-owned assignments and exact undo/redo state.
7. Stop if source health cannot distinguish cache evidence from fresh network evidence in its wording.
8. Stop if JOSM display behavior remains unproved; retain diagnostics and request one targeted reproduction rather than guessing.
9. Stop if private coordinates, archives, logs, credentials, or absolute paths enter tracked files.
10. Stop if exact legacy snapshots, detector attempt completeness, or optimizer determinism change.
