# v0.20.0 Corridor-Aware Default Promotion

**Status:** verified and authorized for release
**Base:** `v0.19.3` / `4e0494e18a5634311bdd1ff28c1ec7f9de2c37f1`
**Target:** `v0.20.0`

## Scope

Promote the already implemented and regression-covered `CORRIDOR_AWARE` tracker
to the default algorithm. Keep `LEGACY_V02` as an explicit compatibility option
and preserve its implementation and outputs. Geometry cleanup remains a separate,
future-candidate-only setting and remains disabled by default.

This promotion completes the minor-version branch permitted by the residual
lateral-stability plan. It does not activate the conditional plateau change,
change palettes or detector ranking, alter sampling, or add another optimizer.

## Preference Contract

- A missing tracker preference selects `CORRIDOR_AWARE`.
- A blank or unknown tracker preference fails to `CORRIDOR_AWARE`.
- An explicitly stored `LEGACY_V02` value remains `LEGACY_V02`.
- An explicitly stored `CORRIDOR_AWARE` value remains `CORRIDOR_AWARE`.
- Saving a null tracker value writes the public default, not a hidden legacy mode.
- Redacted diagnostics describe the same effective default used by alignment.

## Acceptance Criteria

1. New or invalid tracker settings resolve to `CORRIDOR_AWARE` everywhere.
2. Explicit legacy settings round-trip without migration or mutation.
3. Legacy tracker code and explicit-legacy regression outputs are unchanged.
4. Corridor-aware fixture coverage includes broad corridors, sparse corridors,
   sustained sine/switchback geometry, endpoint/junction constraints, palettes,
   and complete all-color aggregation.
5. Geometry cleanup stays disabled unless explicitly enabled.
6. The release jar reports `Plugin-Version: 0.20.0`; tag and release title are
   `v0.20.0`; the primary asset is `wayheatmaptracer.jar`.

## Stop Conditions

- Stop promotion if explicit legacy selection no longer round-trips exactly.
- Stop release on any fixture, topology, undo/redo, privacy, or deterministic
  optimizer regression.
- Do not weaken candidate applicability or topology checks to make tests pass.
